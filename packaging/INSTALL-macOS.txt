Semitone for macOS (Apple Silicon and Intel, macOS 11 or later)

Install
  Semitone.vst3        ->  ~/Library/Audio/Plug-Ins/VST3/
  Semitone.component   ->  ~/Library/Audio/Plug-Ins/Components/
  Semitone.app         ->  anywhere (standalone version, optional)

Then restart your DAW and rescan plug-ins.

"Semitone cannot be opened" / the DAW does not list it
  This build is not signed with an Apple Developer ID or notarised, so macOS
  quarantines it after download. Clear the quarantine flag once, in Terminal:

    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Semitone.vst3
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Semitone.component
